# Mẫu câu trả lời tra cứu chính sách hoàn tiền

Khi trả lời câu hỏi về chính sách hoàn tiền, hãy trình bày rõ ràng theo cấu trúc sau:

- **Chính sách áp dụng:** [Tên chính sách và phạm vi hiệu lực, ví dụ: Chính sách hoàn tiền trước tháng 10 / từ tháng 10]
- **Thời gian:** Ngày mua: [DD/MM/YYYY], Ngày yêu cầu: [DD/MM/YYYY] (Chênh lệch: [X] ngày)
- **Trạng thái kích hoạt:** [Đã kích hoạt / Chưa kích hoạt]
- **Kết luận:** [Đủ điều kiện hoàn tiền / Không đủ điều kiện hoàn tiền (kèm lý do: quá hạn X ngày / sản phẩm đã kích hoạt)]
- **Phí hoàn tiền:** [Không thu phí / 10% giá trị đơn hàng]
- **Căn cứ tài liệu:** [Đường dẫn file chính sách đã tham chiếu, ví dụ: data/policies/policy-before-oct.md]
